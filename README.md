# Календарь учителя

Локальное React-приложение с Firebase Authentication и Cloud Firestore.

## Настройка

1. Скопируйте `.env.local.example` в `.env.local` (файл уже создан локально).
2. Заполните Firebase Web App config в `.env.local`.
3. Установите зависимости и запустите проект:

```bash
npm install
npm run dev
```

Firebase Analytics не используется. В Firestore ожидаются коллекции `users`, `groups`, `lessons` и `payments`. Документ `users/{uid}` должен содержать `name`, `email`, `role` и `schoolId`.

Раздел «Оплаты» доступен ролям `owner` и `admin`. Для применения правил из репозитория опубликуйте `firestore.rules` через Firebase CLI или вставьте их в Firebase Console после проверки совместимости с действующими правилами проекта.

## Доступ учителя

1. Создайте учителя в Firebase Authentication через Email/Password.
2. Создайте документ `users/{uid}` с полями `name`, `email`, `role: "teacher"`, `schoolId: "peakway"`.
3. Войдите администратором, откройте «Учителя» в боковой панели и закрепите за учителем нужные группы.
4. Опубликуйте правила и индексы: `firebase deploy --only firestore`.

Учитель получает только свои группы и уроки. Он может заполнять посещаемость, статус домашней работы и общее домашнее задание, но не видит оплаты и не управляет расписанием.

## Проверка

- Войдите email/password пользователя, созданного в Firebase Authentication.
- Убедитесь, что документ `users/{uid}` существует и имеет `role: "admin"`.
- Создайте группу через плюс в боковой панели — документ появится в `groups` с `schoolId` профиля.
- Создайте занятие кнопкой «Новое занятие» — документ появится в `lessons` с тем же `schoolId`.
- Перетащите карточку или измените её высоту в режиме недели — Firestore обновится автоматически.

# Родительский доступ

Администратор открывает в боковой панели раздел «Родительские ссылки», создаёт нормализованную запись ученика, связывает её с нужной группой и создаёт семейную ссылку. Родителю не нужна регистрация: публичный режим открывается по адресу `?parent=LONG_RANDOM_TOKEN` и показывает только безопасную копию расписания выбранных детей.

Используются коллекции `students`, `parentAccess`, `parentViews` и подколлекция `parentViews/{token}/months`. После обновления проекта обязательно развернуть правила Firestore:

```bash
firebase deploy --only firestore
```

Существующие ученики из журналов уроков автоматически не мигрируют. Их нужно один раз создать в разделе «Родительские ссылки» и связать с соответствующими индивидуальными занятиями, парами или группами.
